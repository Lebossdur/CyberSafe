Qu'est-ce que le hacking éthique ?

Le hacking éthique consiste à tester la sécurité d'un système informatique avec l'autorisation de son propriétaire afin de découvrir et corriger ses failles.

1. La reconnaissance

Les professionnels étudient les informations publiques d'un système pour comprendre comment il fonctionne.

Objectif : identifier les informations qui pourraient être trop facilement accessibles.

2. L'analyse des ports

Un port permet à un ordinateur de communiquer avec un service. Les professionnels vérifient que seuls les services nécessaires sont accessibles.

Objectif : limiter les accès inutiles.

3. Les failles XSS

Une faille XSS peut permettre à du code malveillant de s'exécuter dans le navigateur d'un visiteur à cause d'un site mal protégé.

Protection : vérifier et sécuriser les données affichées sur les pages web.

4. Les injections SQL

Une injection SQL est une faille qui peut apparaître lorsqu'un site intègre incorrectement les données saisies par un utilisateur dans une requête à sa base de données.

Protection : utiliser des requêtes préparées et vérifier les données reçues.

5. L'analyse réseau

Les spécialistes observent les communications entre les appareils pour repérer des échanges inhabituels ou mal sécurisés.

Objectif : mieux comprendre et protéger les échanges de données.

6. Les mots de passe

Les experts évaluent la solidité des mots de passe dans un cadre autorisé afin de repérer les mauvaises pratiques.

Protection : utiliser des mots de passe longs, uniques et la double authentification.

La règle numéro 1

Un test de sécurité doit toujours être réalisé avec l'autorisation du propriétaire du système. Tester un site ou un compte sans autorisation peut être illégal.
